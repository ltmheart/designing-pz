# Практична робота — Система пошуку курсів валют (варіант 1)

**Мова:** C++, Visual Studio 2022, Windows, два окремі застосунки.

## 1. Як запустити
1. Розпакуй архів і відкрий **CurrencyEasy.sln** у Visual Studio.
2. Зверху вибери **Debug** та **x64**.
3. Натисни **Ctrl + Shift + B** (Build Solution).
4. Подвійним кліком запусти **RunBoth.bat** з папки проєкту.
5. У браузері відкрий **http://127.0.0.1:8080/**.
6. Введи `USD`, суму `10` і вибери `UAH`, натисни кнопку.
   Результат залежить від **справжнього курсу НБУ**.

Для перевірки API окремо: **http://127.0.0.1:8081/api/rate?code=USD**

> Наявність інтернету потрібна, оскільки сервіс звертається до сайту НБУ.
> Текст зберігається в UTF-8, параметр компіляції `/utf-8` увімкнений, код Windows UTF-8 встановлений у main().

## 2. З чого складається програма

- **Currency.Service/main.cpp** — мікросервіс: приймає код валюти (USD, EUR...), отримує реальний курс з НБУ, повертає JSON.
- **Currency.Web/main.cpp** — вебпрограма: показує HTML-сторінку, перевіряє введення, запитує перший сервіс і конвертує суму.
- **Shared/Network.h** — допоміжні HTTP-функції для Windows; можна сприймати як готовий інструмент, щоб не писати мережу щоразу з нуля.
- **Shared/Nbu.h** — функція `askNbu()` для запиту до API НБУ по HTTPS.

**MVC у Currency.Web, але без купи файлів:**
- Model: `struct Currency` — дані про валюту.
- View: `view()` — будує HTML-сторінку.
- Controller: `controller()` — перевіряє введення і звертається до сервісу.

## 3. Що робить користувач

1. Вводить код валюти — наприклад, `USD`.
2. Вибирає, у що конвертувати: `UAH`, `EUR`, `USD` або `PLN`.
3. Вводить суму, наприклад `10`.
4. Натискає **Показати курс і конвертувати**.
5. Бачить назву валюти, її курс у гривнях, дату курсу та результат.

**Формула:** `результат = сума * курс_початкової / курс_кінцевої`.
Наприклад, якщо 1 USD = 40 грн, 1 EUR = 50 грн, то 10 USD = 10 × 40 / 50 = 8 EUR.
Ці числа — лише приклад формули, не реальний курс.

## 4. Як перевірити помилки
- Код `ABC` → «Валюту ABC не знайдено» (якщо НБУ відповідає порожнім списком).
- Код `12` → «Введіть коди валют з трьох латинських літер».
- Сума `-5` або букви → «Введіть правильну додатну суму або нуль» (або перевірка браузера не дасть відправити форму).
- Якщо закрити консоль **Currency.Service**, вебсторінка покаже «Currency.Service не запущений».
- Якщо вимкнути інтернет і спробувати валюту, сервіс поверне помилку 502 (НБУ недоступний).

## 5. Коротко для захисту

> «Я виконала варіант 1 — пошук курсів валют. Написала дві окремі програми на C++. Перша — Currency.Service — отримує актуальні курси з API НБУ та повертає JSON. Друга — Currency.Web — показує форму, звертається до першого сервісу через HTTP і рахує конвертацію. Усередині Currency.Web я використала MVC: Model зберігає дані, View показує сторінку, Controller обробляє запит. Перевірила помилки: неправильний код, відсутня валюта, недоступний сервіс».

**Чому саме мікросервіси?** Дві програми працюють окремо та спілкуються HTTP-запитом: порт 8080 — сторінка, порт 8081 — API.

**JSON** — текстовий формат даних, наприклад `{"code":"USD","name":"Долар США","rate":...}`.

## 6. Якщо не запускається
- Якщо бачиш `{"error":"Адресу не знайдено"}` за адресою `127.0.0.1:8081`, це нормально: на 8081 немає головної сторінки. Відкривай **8080**.
- Якщо `8080` не відкривається, переконайся, що вікно **Currency.Web** не закрилося.
- Якщо повідомлення про зайнятий порт, закрий старі копії консольних програм з попередньої практичної.
- Якщо Visual Studio не збирає, у Visual Studio Installer має бути компонент **Desktop development with C++**.
- Якщо `byte is ambiguous`, **не пиши `using namespace std;` до `#include <windows.h>`**. У цих файлах такого немає.

## 7. Відповідність вимогам варіанта 1
1. API-сервіс — Currency.Service: є.
2. Пошук за кодом — є, можна вводити трилітерний код.
3. Код, назва, курс, дата — повертаються у JSON.
4. Інтерфейс і конвертація — є.
5. Помилки невідомої валюти і недоступного API — обробляються.

Дані НБУ — офіційний довідковий курс до гривні, а не купівля/продаж готівки.

*Технічна примітка:* HTTP-сервер написаний спеціально як мінімальний локальний навчальний приклад. Він слухає лише 127.0.0.1, не призначений для використання в інтернеті.
