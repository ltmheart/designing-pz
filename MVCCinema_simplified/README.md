# MVCCinema — проста практична робота MVC (C++)

## Як відкрити
1. Розпакуйте ZIP.
2. Відкрийте `MVCCinema.slnx` у Visual Studio 2022 з установленим компонентом **Desktop development with C++**.
3. Запустіть через **Ctrl+F5**.

## Що робить програма
- `1` — показує три фільми, ціну й кількість місць.
- `2` — купує **один** квиток за номером фільму (місць стає на одне менше).
- `0` — завершує програму.
- Помилки: текст замість числа, невідомий пункт меню, неправильний номер фільму або відсутність місць.

## Де MVC
- `Model.h` / `Model.cpp` — дані про фільми та метод `buyTicket`.
- `View.h` / `View.cpp` — меню, виведення і введення користувача.
- `Controller.h` / `Controller.cpp` — реагує на команди користувача, з'єднує Model та View.
- `main.cpp` — налаштовує консоль і запускає Controller.

## Український текст
- Початкові файли збережено у **UTF-8**.
- У `main.cpp` задано `SetConsoleCP(CP_UTF8);` та `SetConsoleOutputCP(CP_UTF8);`.
- У налаштуваннях проєкту додано параметр компілятора `/utf-8`.
- Якщо консоль показує некоректні символи, запускайте у Windows Terminal або сучасній консолі Windows з шрифтом, що підтримує кирилицю.

## Для захисту
«Я створила консольну програму кінотеатру з патерном MVC. Model зберігає фільми і зменшує кількість місць при купівлі. View виводить меню і приймає дані. Controller обробляє вибір та викликає Model і View. Є перевірка введення та відсутності квитків. Український текст працює через UTF-8».
